# TPOWebPage

Proyecto final realizado para el **curso de Trayecto programador en Python** . 

## Descripción 
El objetivo del proyecto fue desarrollar una aplicación web utilizando **Python Flask** con una base de datos SQL.

La aplicación permite conectar la interfaz web con la base de datos a través del backend desarrollado en Python, aplicando los conocimientos adquiridos durante el curso.

El proyecto permitio trabajar de forma integrada con distintos componentes de una aplicación web:
- Desarrollo del backend utilizando Python.
- Uso del framwork **Flask** para la creacion de la aplicacion.
- Conexion de la aplicacion con una base de datos SQL
- Interaccion entre la interfaz web, el servidor y la base de datos.
- Organizacion de la logica de la aplicacion.
- Manejo y consulta de informacion almacenada en una base de datos

## Tecnologias Utilizadas
- Python
- Flask
- SQL
- HTML
- CSS
- GITHUB
